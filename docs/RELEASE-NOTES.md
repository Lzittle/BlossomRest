# 0.1.0 测试版

本版面向小范围体验与兼容性验证，尚未宣告完整通过正式发布验收。

## 已提供

- 同一程序即时切换简体中文与英文，保存语言选择；安装向导和使用说明提供两种语言，用户内容保持原文。

- 托盘常驻、浮窗展开收起、隐藏唤回与位置记忆。
- 文件、文件夹、文字、图片的收录和复制；多选路径与文字、RTF 图文混合复制。
- 工作区分组、搜索过滤、图片与视频缩略图。
- 移动到文件夹、重名不覆盖和单级撤销；机器生成名的语义建议显示名。
- 清理策略、单击行为、开机自启和系统主题跟随设置。
- 自包含便携版与当前用户安装版；卸载保留用户数据。

## 使用边界

- 不联网、不遥测、不自动发送消息；自动采集默认关闭。
- 微信等目标一次粘贴可能只接收一种格式，文字可单独复制。
- 视频缩略图依赖系统解码器；无法生成时显示类型图标。
- 文件夹不支持跨盘移动；移动撤销仅当前进程有效。
- 贴边竖条仍为后续设计提案，本版使用现有收起形态。
- 多屏与 125% / 150% / 200% 缩放、输入法焦点、跨应用投递仍需实际环境确认。
- 本版未签名，不包含在线更新。

需求文档中的 v0.2 / v0.3 为功能规划阶段，当前下载文件与程序实际版本统一为 0.1.0。
