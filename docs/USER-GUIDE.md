# 花托 · Blossom Rest 使用说明

当前版本：0.1.0 测试版，Windows 10 1809+ / Windows 11，64 位。

## 安装与启动

- 安装版：运行 `BlossomRest-0.1.0-win-x64-setup.exe`，按中文向导安装。仅为当前用户安装，无需管理员权限，不会自动开启自启。
- 便携版：完整解压 ZIP，进入 `BlossomRest-win-x64` 文件夹，运行 `TransitShelf.exe`，不要只取出 exe。
- 默认分发的是自包含版，无需另外安装 .NET。标明“框架依赖”的包才需要 .NET 8 桌面运行时。
- 程序常驻托盘；再次运行不会创建第二个实例。升级、卸载前请先从托盘退出。

## 放入与取出

1. 把文件、文件夹、文字或图片拖入小框，也可通过“添加”菜单选择文件或文件夹。
2. 按 `Ctrl+Alt+C` 收录当前剪贴板；按 `Ctrl+Alt+D` 显示或收起小框。
3. 默认单击文件夹打开，单击其他条目复制；双击打开，也可使用右键菜单。设置中可以调整单击行为。
4. 多选后可复制所选内容。微信等应用一次可能只取文件；再点“复制文字”补贴文字。支持 RTF 的 Word/WPS 等应用可接收图文混合内容。
5. 工作区默认关闭，在设置中开启后可创建分组，长期保存常用引用。

## 保存与文件安全

- 文件和文件夹通常只保存路径引用，不产生内容副本。删除条目不会删除原始文件。
- “移动到文件夹”和磁盘重命名会真实改变文件位置或名称，请核对确认窗口。移动重名时追加序号，不覆盖；撤销只保留本次运行最近一次移动。文件夹不支持跨盘移动。
- “建议名称”只修改架子里的显示名，不修改磁盘文件名。
- 条目、分组和设置保存在 `%LOCALAPPDATA%\TransitShelf\state.json`；无源图片保存在同目录 `cache` 中。备份时先退出程序，再备份整个 `TransitShelf` 数据目录。
- 便携版的“便携”指程序免安装，数据仍在上述用户目录。更新程序和卸载均保留该目录；程序运行后的过期清理和退出清空仍按你的设置执行。
- 目录自动采集默认关闭；无网络、无账号、无遥测。

## 找回浮窗与退出

悬浮球隐藏后，可双击托盘图标、选择托盘“显示中转站”或按 `Ctrl+Alt+D` 唤回。关闭面板不代表退出；完全退出请使用托盘菜单。

## 测试版限制

测试版尚需在更多多屏与缩放、输入法、微信和富文本目标环境中验证。暂未提供代码签名。请从可信来源取得压缩包或安装包，并核对同名 `.sha256` 文件；不要为了安装关闭系统安全功能。使用过程中遇到问题可记录操作步骤、系统缩放、目标应用版本，提交到项目的问题反馈区；截图前请遮挡真实路径和文字。
